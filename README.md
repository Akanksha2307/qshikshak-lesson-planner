# Qshikshak Lesson Planner – Frontend Prototype

School-focused React/Vite frontend prototype using localStorage only (no backend/API required).

## Included
- Role-aware navigation for Teacher, HOD, Principal, Admin and Parent
- Teacher Today dashboard
- Proper Teaching Calendar with Day / Week / Month views, six period timings, lesson topics, class/section, teacher, holidays and examination blocks
- Lesson plan auto-generation from raw syllabus data with holiday/exam skipping
- Rich lesson preparation: objectives, prerequisites, teaching method, resources, homework, assessment and notes
- Delivery/completion workflow, lesson history, HOD approvals, reports, homework, examinations, holidays, classes/sections
- Raw demo data for Classes 1–10, sections, five subjects, SSC/CBSE/ICSE syllabus chapters/topics, holidays, exams and sample lessons
- Timetable page removed; timetable-style scheduling is now integrated into Teaching Calendar

## Run
```bash
npm install
npm run dev
```

If an older version was opened before, use the reset icon in the top bar. This build also uses a new localStorage version key so the new demo data loads automatically.
